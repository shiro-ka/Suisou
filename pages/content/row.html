Row

行。持つのは余白・角丸・下地の反応だけ。 中身の並べ方は Media が持つので、同じ要素に両方書ける —— 当たる CSS プロパティが重ならない。 作例では14箇所（チャット5・一覧9）に出ていた。

2つの形

既定 —— 角丸。容れ物の中に浮く
しろか — テーマ名を水域にした
相棒 — 値は変えていません
しろか — hover の色ってどう決まってる？
ruled —— 角丸なし＋下罫。端から端まで連なる
選択下地をアクセント色のままにするか
panel の余白に段を足す
block ボタンの既定を左寄せにする

ruled は surface="bleed" と組で使う —— 行が自分で余白を持つので、容れ物の側は余白を持たない。 最後の1本は引かないので、下端で罫が二重にならない。

すきまは書かなくていい。ruled の行を子に持つ入れ物は :has() で gap: 0 になる —— すきまは親が持っていて行からは消せないので、 Suisou 側で面倒をみている。

ruled角丸なし、上下 8px、下罫 一覧。surface="bleed" の中に敷き詰める
