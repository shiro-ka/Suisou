Notice

Noticeの適用

要素に data-suisou-item="notice" を追加します

<p data-suisou-item="notice">

お知らせです

<p data-suisou-item="notice">お知らせです</p>

色

error / warning / success を追加すると、色が変わります

メールアドレスかパスワードが違います

この操作は取り消せません

確認メールを送信しました

<p data-suisou-item="notice error">メールアドレスかパスワードが違います</p>
<p data-suisou-item="notice warning">この操作は取り消せません</p>
<p data-suisou-item="notice success">確認メールを送信しました</p>

Reference

Values

ValueFunction
notice知らせの箱にする。背景を item の色にし、細い罫線・角丸を付ける。余白は縦 8px・横 16px、文字は本文の色
error warning successnotice と一緒に使う。罫線をその色に、背景をその色の薄い色にする。1つまで

CSS

[data-suisou-item~="notice"] {
  background: var(--suisou-item);
  --suisou-line-weak: var(--suisou-line-weak-item);
  --suisou-line-strong: var(--suisou-line-strong-item);
  border: 1px var(--suisou-bd-style, solid) var(--suisou-line-weak);
  border-radius: var(--suisou-radius);
  padding: var(--suisou-space-2) var(--suisou-space-3);
  color: var(--suisou-text-main);
}

[data-suisou-item~="notice"]:where([data-suisou-item~="error"])   { border-color: var(--suisou-error);   background: var(--suisou-error-surface); }
[data-suisou-item~="notice"]:where([data-suisou-item~="warning"]) { border-color: var(--suisou-warning); background: var(--suisou-warning-surface); }
[data-suisou-item~="notice"]:where([data-suisou-item~="success"]) { border-color: var(--suisou-success); background: var(--suisou-success-surface); }
