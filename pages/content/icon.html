Icon

単独で置く <svg> の寸法と色。 部品の中に置くなら要らない —— Button と Tag は自分の中の svg の寸法を持っているので、そのまま放り込めば揃う。 これが要るのはどの部品にも属さないとき（一覧の状態しるし、空表示など）。

寸法

data-suisou-icon
20px（既定）
data-suisou-icon="small"
16px。12px の文字の隣に置く用
値寸法トークン
（書かない）20px--suisou-icon
small16px--suisou-icon-small

色 —— 1つ選ぶ

Tag と同じ閉じた集合。書かなければ currentColor のままで、 文字と一緒に色が動く。以前は作例側で style="--c: var(--suisou-success)" と書かせていて、 任意の色を差し込める穴になっていた。

状態のしるし
success warning error accent sub

sub があるのは Tag との違い。Tag は既定が text-sub だが、 Icon の既定は継承なので、弱めたいときに名指しする語が要る。

部品の中では要らない

Button と Tag は自分で寸法を持つ
属性なし

どちらも > svg で自分の中の svg を面倒みている。 寸法の指定が2通りあるように見えるが、使う側が選ぶ場面は無い —— 部品の中なら書かない、外なら書く。
