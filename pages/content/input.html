Input

Inputの適用

<input>, <textarea>, <select> タグの要素はインプットになります

<div data-suisou-layout="stack">
  <input>
  <textarea></textarea>
  <select><option>選択肢</option></select>
</div>

状態

aria-invalid="true" をつけると、エラー表示になります
disabled / aria-disabled="true" をつけると、選択できない状態になります

<div data-suisou-layout="stack">
  <input aria-invalid="true">
  <input disabled>
</div>

Reference

Values

ValueFunction
なしdata-suisou-body の中の <input> <textarea> <select> を入力欄にする。<input> の checkbox radio range color file submit button reset image hidden には当たらない。高さ 32px、横の余白 8px、角丸、濃い罫線。背景は置いた場所より一段上の色。幅は指定しない。プレースホルダーは薄い文字。フォーカスで枠が付く。aria-invalid="true" で罫線を赤く、disabled aria-disabled="true" で文字と罫線を薄くして背景を消す

CSS

:where([data-suisou-body] :is(input:not([type="checkbox"], [type="radio"], [type="range"], [type="color"], [type="file"], [type="submit"], [type="button"], [type="reset"], [type="image"], [type="hidden"]), textarea, select)) {
  padding: calc((var(--suisou-control) - 1lh) / 2 - 1px) var(--suisou-space-2);
  border-radius: var(--suisou-radius);

  background: var(--suisou-next, var(--suisou-item));
  --suisou-line-weak: var(--suisou-line-weak-next, var(--suisou-line-weak-item));
  --suisou-line-strong: var(--suisou-line-strong-next, var(--suisou-line-strong-item));
  color: var(--suisou-text-main);
  border: 1px var(--suisou-bd-style, solid) var(--suisou-line-strong);
  transition: border-color var(--suisou-motion-fast) var(--suisou-ease);
}

:where([data-suisou-body] select:not([multiple], [size])) {
  padding-block: 0;
  block-size: var(--suisou-control);
}

:where([data-suisou-body] :is(input, textarea))::placeholder { color: var(--suisou-text-disabled); }

:where([data-suisou-body] :is(input, textarea, select)):focus-visible {
  outline: var(--suisou-focus);
  outline-offset: 2px;
}

:where([data-suisou-body] :is(input, textarea, select))[aria-invalid="true"] { border-color: var(--suisou-error); }

:where([data-suisou-body] :is(input, textarea, select)):disabled,
:where([data-suisou-body] :is(input, textarea, select))[aria-disabled="true"] {
  color: var(--suisou-text-disabled);
  border-color: var(--suisou-line-weak);
  background: transparent;
  cursor: default;
}
