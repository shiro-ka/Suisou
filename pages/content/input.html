Input

Inputの適用

<input>, <textarea>, <select> タグの要素はインプットになります
スタイルの当たらない <input> の type もあります。Reference をご確認ください

<div data-suisou-layout="stack">
  <input>
  <textarea></textarea>
  <select><option>選択肢</option></select>
</div>

状態

aria-invalid="true" をつけると、エラー表示になります
disabled / aria-disabled="true" をつけると、操作できない状態になります

<div data-suisou-layout="stack">
  <input aria-invalid="true">
  <input disabled>
</div>

チェックボックス・ラジオボタン

type が checkbox / radio の <input> は、チェックボックス / ラジオボタンになります

<div data-suisou-layout="row wrap">
  <label><input type="checkbox"> 未選択</label>
  <label><input type="checkbox" checked> 選択</label>
  <label><input type="checkbox" disabled> 無効</label>
</div>
<div data-suisou-layout="row wrap">
  <label><input type="radio" name="fish" checked> ネオンテトラ</label>
  <label><input type="radio" name="fish"> オトシンクルス</label>
</div>

Values

ValueFunction
なしdata-suisou-body の中の <input> <textarea> <select> を入力欄にする。<input> の type が range, color, file, submit, button, reset, image, hidden のときはインプットになりません。高さ 32px、横の余白 8px、角丸、濃い罫線。背景は置いた場所より一段上の色。幅は指定しない。プレースホルダーは薄い文字。フォーカスで枠が付く。aria-invalid="true" で罫線を赤く、disabled aria-disabled="true" で文字と罫線を薄くして背景を消す
checkbox radiotype が checkbox / radio の <input> を 16px の枠にする（チェックボックスは角丸、ラジオボタンは丸）。選ぶと背景がアクセント色になり、印が出る。JS で indeterminate を付けたチェックボックスは横棒になる。マウスを乗せると枠がアクセント色、disabled で枠を薄くする
