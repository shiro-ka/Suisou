Components

Suisou のものは data-suisou-* 属性。class は使わない ―― class は 適用先のもので、ユーティリティ（ui/layout.css）だけが例外。 状態は aria-* と disabled を借りる。値は空白区切りで ~= が拾う。

Button

塗らない。CTA すらアウトライン。hover で面の明度は動かさず hover-surface を敷く。基本形が「罫なし」なのは実測から ―― wixdex の <button> 84個のうち 26個がアイコンのみで、 単独では最大の塊だった。

data-suisou-btn
data-suisou-btn="… icon"

値を並べれば掛かる。属性は1つのまま。アイコンの寸法は部品が持つので、 使う側は書かない。currentColor なので色も継承される。

data-suisou-btn-group（連結）

親が罫と角丸を持ち、overflow で子を切る。子は角丸を持たないので 何個並んでも破綻しない。wixdex の検索欄がこの作りだった。

無効
data-suisou-btn="… block"

★danger の hover と active は色を動かしていない。仕様書に 「意味色は状態を持たない。destructive なボタンは v1.2 のスコープ外」とあり、 error の押下色が solve.py に無いため。下地だけで反応させている。
