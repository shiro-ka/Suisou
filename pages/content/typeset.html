Typeset

Typesetの適用

要素の data-suisou-text に typeset を追加すると、中の要素がドキュメントの見た目になります

<article data-suisou-text="typeset">

  • 水温を合わせる

  <h2>水換え</h2>

  <ul>
    <li>カルキ抜きを入れる</li>
    <li>水温を合わせる</li>
  </ul>
</article>

Reference

Values

ValueFunction
typeset中の要素を長文の見た目にする。本文 14px・行の高さ 24px。fs-* を一緒に書くと本文の文字だけが変わり、見出しや隙間は変わらない

Elements

ElementFunction
h1 〜 h424 / 20 / 16 / 14px の太字。h2 〜 h4 は左に帯（h2 塗り、h3 中抜き、h4 灰色の塗り）。h5 h6 は h4 と同じ
p ul ol dl前に 8px。リストは左に 24px 字下げ、項目の間 4px
h2前に 48px、後に 16px
h3前に 24px（見出しの直後は 16px）
h4 〜 h6前に 16px
strong b太字
code等幅・背景付き。途中で折り返さない
a下線。マウスを乗せるとアクセント色。画像だけのリンクには下線を付けない
small12px
dt dddt は note の色の太字、dd はその下に 24px 字下げ。組の間 16px
hr薄い罫線。前後 16px
blockquote罫線と角丸の囲い、左上に引用符のアイコン。文字は note の色
pre罫線と角丸の囲い、1行目にコードのアイコン。12px の等幅で、長い行は横にスクロール
figure ＋ figcaption ＋ prefigure が囲いを持ち、figcaption がアイコン付きのヘッダーになる
table幅いっぱい・12px。thead の行に背景と上の角丸、th は折り返さない。行の間に罫線
details罫線と角丸の囲い。summary は太字で左に矢印。マウスを乗せると背景が付き、キーボードで移動すると accent の枠が付く。開くと区切り線が付き、中身がふわっと出る
img video中央に置き、幅 640px・高さ 480px（画面の高さの半分の方が小さければそちら）まで。角丸
figure ＋ figcaptionキャプションを画像の下 8px に 12px・note の色・中央揃えで置く
blockquote pre table details figure img video前後に 24px（h2 の直後は 16px）
