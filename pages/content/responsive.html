Responsive

Responsiveの適用

値の前に s: / m: / l: を付けると、その画面幅以上のときだけ当たります
s は 768px、m は 1024px、l は 1280px です

<div data-suisou-layout="stack s:row">
1
2
3
<div data-suisou-layout="stack s:row">
  <div data-suisou-item>1</div>
  <div data-suisou-item>2</div>
  <div data-suisou-item>3</div>
</div>

画面幅で大きさが変わる文字

<p data-suisou-text="fs-14 s:fs-20 m:fs-28">画面幅で大きさが変わる文字</p>

狭いときだけ

hidden と invisible は、s> / m> / l> で、その幅より狭いときだけ当たります

スマホでは消える文

PC では消える文

<p data-suisou="s>hidden">スマホでは消える文</p>
<p data-suisou="s:hidden">PC では消える文</p>

使える値

layout / text / data-suisou / body で使えます

属性値
data-suisou-layoutstack row grid wrap grow stretch center middle end between
data-suisou-textfs-12 fs-14 fs-16 fs-20 fs-24 fs-28 fs-32
data-suisoumin-screen scroll-y scroll-x hidden invisible
data-suisou-bodydock

Values

ValueFunction
s: m: l:画面幅が 768 / 1024 / 1280px 以上のときだけ当たる（@media (width >= 768px) など）。前置きの無い値はすべての幅に当たり、前置きの付いた値がその幅から上書きする
s> m> l>画面幅が 768 / 1024 / 1280px より狭いときだけ当たる（@media (width < 768px) など）。hidden と invisible だけで使える
