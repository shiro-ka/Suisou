headタグ

テーマをインポート

Suisouの<link>タグを設置し、インポートします

<link rel="stylesheet" href="https://suisou.pages.dev/v3/suisou.css">

通常のsuisou.cssはすべてのテーマが入っています

テーマ切り替えが必要ない場合は、suisou-[プライマリ]-[アクセント].cssで単テーマのスタイルもインポート可能です

(shoal x jelly の場合)

<link rel="stylesheet" href="https://suisou.pages.dev/v3/suisou-shoal-jelly.css">

フォントをインポート

Suisouの規定フォントは Zen Maru Gothic です
Google Fonts等からインポートを行ってください

<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Zen+Maru+Gothic:wght@400;500;700&display=swap" rel="stylesheet">

Zen Maru 以外を使用する場合は、変数を書き換えます

:root { --suisou-font: "Your Font", sans-serif; }

バージョン

URLのv3はSuisouのバージョンです
常に最新のバージョンが配信されるため、更新で見た目が変わることがあります

現在、v2もインポートすることはできますが、仕様が大きく異なるため非推奨です
