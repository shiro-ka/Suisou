Layout

Layoutの適用

要素に data-suisou-layout を追加すると、直下の子要素の並べ方が決まります

stack

子要素を縦に並べ、子は横幅いっぱいに伸びます

<div data-suisou-layout="stack">
1
2
3
<div data-suisou-layout="stack" data-suisou-tray>
  <div data-suisou-item>1</div>
  <div data-suisou-item>2</div>
  <div data-suisou-item>3</div>
</div>

row

子要素を横に並べ、子は縦の真ん中に揃います

<div data-suisou-layout="row">
1
2
2
3
<div data-suisou-layout="row" data-suisou-tray>
  <div data-suisou-item>1</div>
  <div data-suisou-item>2<br>2</div>
  <div data-suisou-item>3</div>
</div>

grid

子要素を升目に並べます

既定値

1列の横幅は12rem以上で、親の幅に入るだけ列が作られます
入りきらない子要素は次の行に回ります

<div data-suisou-layout="grid">
1
2
3
4
5
6
<div data-suisou-layout="grid" data-suisou-tray>
  <div data-suisou-item>1</div>
  <div data-suisou-item>2</div>
  <div data-suisou-item>3</div>
  <div data-suisou-item>4</div>
  <div data-suisou-item>5</div>
  <div data-suisou-item>6</div>
</div>

列・行の指定

変数 --suisou-grid-cols と --suisou-grid-rows に値を渡すと、列と行を指定できます
渡す値は CSS の grid-template-columns / grid-template-rows と同じ書き方です

<div data-suisou-layout="grid" style="--suisou-grid-cols: repeat(3, minmax(0, 1fr))">

1fr だけで書くと、長い語や画像で列が枠からはみ出します。minmax(0, 1fr) で書くとはみ出しません

Reference

Values

ValueFunction
stack子要素を縦に並べる。子は横幅いっぱいに伸びる
row子要素を横に並べる。子は縦の真ん中に揃う
grid子要素を升目に並べる。1列12rem以上で、親の幅に入るだけ列を作る。列と行は --suisou-grid-cols / --suisou-grid-rows で指定できる
gap-0 gap-1 gap-2 gap-3 gap-4子要素の間隔を 0 / 4 / 8 / 16 / 24px にする。書かなければ 8px
middle end between並ぶ向きに、真ん中・終わり・両端へ寄せる
stretch center並ぶ向きと直角に、伸ばす・真ん中に揃える
wrap入りきらない子要素を折り返す
grow子要素に付ける。余った分を埋める。比率は --suisou-grow で変えられる。付けていない子要素は縮まない
s: m: l:値の前に付けると、768 / 1024 / 1280px 以上でだけ効く。並べ方・揃え・wrap・grow に付けられる
