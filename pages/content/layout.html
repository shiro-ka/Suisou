Layout

並び。属性を付けた時点で display: flex と gap: 8px（space-2）が入る。 すきまは焼き込んである —— Suisou の間合いは毎回選ぶものではない。 値は空白区切りで重ねるので、属性はいくつ語を並べても1つ。 cols や fill という汎用の名前を class として 世界から奪わないために、並びは属性の中の語にしてある。

スクロールバー

scroll は溝（scrollbar-gutter: stable）を常に確保する —— 中身が増えてバーが出た瞬間に横幅が縮むのを止めるため。 色と太さは根（data-suisou-root）が持ち、継承で全部に届く。 つまみは line-strong、溝は透明。線1本だけが見える。 標準の scrollbar-width / scrollbar-color だけを使い、 ::-webkit-scrollbar は書かない —— あちらは標準化されたことがなく、 同じことが標準側でできるようになった。

すきまを変える

既定は space-2（8px）。これが Suisou の間合いなので、 揃えるだけなら何も書かない。現場が変えたいときは helpers.css の .gap-* を重ねる —— 汎用のユーティリティは接頭辞を持たない。 Tailwind など他のユーティリティが既にあるなら helpers.css は読み込まず、 そちらの gap-4 がそのまま効く。
