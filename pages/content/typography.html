Typography

右端の数値は「サイズ / 行間 / ウェイト」。CSS に書いた表ではなく、 実際に効いている computed 値を読んで出している。根拠は type-spec。

サイズスケール — UI（アンカー 14px）

14 以外はすべて4の倍数。等比スケールは採らない（§3）。

サイズスケール — 長文（アンカー 16px）

行間は UI に +4px するだけ。表ではなく規則として持っている（§6）。

ウェイト

階層はサイズだけで作らない。実測で最頻出の見出しは「14px + semibold」だった（§4）。段は3つ —— Zen Maru Gothic が 600 を持たないため、600 は廃止して 700 が引き受ける。

色

data-suisou-text="s14 sub"

補足・注記。3段目の弱い文字はこれ

data-suisou-text="s14 accent"

アクセント。枠や配置と併せて使う

data-suisou-text="s14 success / warning / error"
保存しました 取り消せません 保存に失敗しました

Icon と同じ閉じた集合。書かなければ継承（currentColor のまま）。 disabled の段は無い —— --suisou-text-disabled は disabled / placeholder 専用で、overlay の上で 3.23:1（WCAG 1.4.3 の除外規定に依る値）。 本文に使うと基準を割るので、段を作らない。薄い注記が欲しいときは sub がその役。

行の寄せ

data-suisou-text="s14 center"

中央に寄せた行

data-suisou-text="start" —— button の既定（中央）を行に戻す

text-align は layout の寄せとは別物。 layout の middle / end は 箱の並べ方（主軸の余りの配り方）で、こちらは行ボックスの中の話。 同じ名前を layout に置くと、どちらの軸を言っているのか読めなくなるので text に持たせた。

★start は打ち消しの語。単体で書いても普通は何も変わらない —— ブラウザが button の中身を中央に寄せるので、それを行に戻すために要る。

★end は持たない。実測で2件しか無く（どちらも数値の列）、3回に届かなかった。 画面幅で寄せを変える s: / m: も、需要が2現場とも0だったので作らない。

1行に収める

data-suisou-text="w500 one-line"
とても長いデッキ名がここに入って画面からはみ出す
flex の子でも効く（min-width: 0 を含むため）
▣
とても長いデッキ名がここに入って画面からはみ出す

★2 現場が同じ 4 行を別の名前で発明していたので昇格させた（実測 10 箇所）。

★min-width: 0 まで持つのが肝。3 行そろって初めて効くうえ、 flex の子は min-width の既定が auto なので、 3 行書いても縮まず溢れる。片方の現場はこの 4 行目を書いていて、 もう片方は書いていなかった —— 忘れるのは仕組みの側の落ち度。 ブロック要素では既定が 0 なので、書いても何も起きない。

★名前は現場が自分で付けた one-line を採った。 ellipsis は「…」という見た目の名前だが、 やりたいのは「1 行に収める」で、そちらが意図に近い。

★N 行で切る（line-clamp）はまだ持たない。 1 現場に 3 箇所あるだけで、行数を値に取るので語の形も変わる。2 現場目が出てから。

数字の幅を揃える

既定 —— 桁が変わると幅が動く
1,1118,888
data-suisou-text="tabular"
1,1118,888

数が動く場所（順位・枚数・カウンタ・残り文字数）で、桁が変わるたびに 文字幅が変わって隣の要素が跳ねる。実測 4 箇所（2 現場）。

★等幅フォントに切り替えるのとは違う。書体はそのままで数字の字送りだけを揃えるので、 見出しの中の数字にも使える。
