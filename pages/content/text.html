Text

Textの適用

要素に data-suisou-text を追加し、文字の見た目を変更できます

<p data-suisou="accent" data-suisou-text="fs-20 fw-700">

Text

<p data-suisou="accent" data-suisou-text="fs-20 fw-700">Text</p>

大きさ

fs-* を追加すると、文字の大きさが変わります
値は fs-12 / fs-14 / fs-16 / fs-20 / fs-24 / fs-28 / fs-32 があります

fs-12

fs-14

fs-16

fs-20

fs-24

fs-28

fs-32

<div>
  <p data-suisou-text="fs-12">fs-12</p>
  <p data-suisou-text="fs-14">fs-14</p>
  <p data-suisou-text="fs-16">fs-16</p>
  <p data-suisou-text="fs-20">fs-20</p>
  <p data-suisou-text="fs-24">fs-24</p>
  <p data-suisou-text="fs-28">fs-28</p>
  <p data-suisou-text="fs-32">fs-32</p>
</div>

太さ

fw-400 / fw-500 / fw-700 を追加すると、文字の太さが変わります

fw-400 fw-500 fw-700 
<div data-suisou-layout="row wrap">
  <span data-suisou-text="fw-400">fw-400</span>
  <span data-suisou-text="fw-500">fw-500</span>
  <span data-suisou-text="fw-700">fw-700</span>
</div>

色

data-suisouでnote / accent / success / warning / error を追加すると、色が変わります

note accent success warning error 
<div data-suisou-layout="row wrap">
  <span data-suisou="note">note</span>
  <span data-suisou="accent">accent</span>
  <span data-suisou="success">success</span>
  <span data-suisou="warning">warning</span>
  <span data-suisou="error">error</span>
</div>

寄せ

start / center / end を追加すると、行の中で文字を寄せる位置が変わります

start

center

end

<div>
  <p data-suisou-text="start">start</p>
  <p data-suisou-text="center">center</p>
  <p data-suisou-text="end">end</p>
</div>

clamp

clamp-1 を追加すると、文字が1行に収まり、はみ出した分は … に省略されます

水槽の水はろ過フィルターを通って少しずつ循環し、水草が光を受けて酸素を出し、底砂の微生物が汚れを分解して、ガラスの中の小さな生態系がゆっくりと回り続けます

<p data-suisou-item data-suisou-text="clamp-1">水槽の水はろ過フィルターを通って少しずつ循環し、水草が光を受けて酸素を出し、底砂の微生物が汚れを分解して、ガラスの中の小さな生態系がゆっくりと回り続けます</p>

clamp-2 を追加すると、文字が2行に収まり、はみ出した分は … に省略されます

水槽の水はろ過フィルターを通って少しずつ循環し、水草が光を受けて酸素を出し、底砂の微生物が汚れを分解して、ガラスの中の小さな生態系がゆっくりと回り続けます。水換えは週に一度、3分の1ほどを入れ替えます

<p data-suisou-item data-suisou-text="clamp-2">水槽の水はろ過フィルターを通って少しずつ循環し、水草が光を受けて酸素を出し、底砂の微生物が汚れを分解して、ガラスの中の小さな生態系がゆっくりと回り続けます。水換えは週に一度、3分の1ほどを入れ替えます</p>

link

link を追加すると、下線が付きホバーで色が変わります

組版は Typeset のページへ

<p>組版は <a href="#typeset" data-suisou-text="link">Typeset</a> のページへ</p>

アイコン

<svg> に追加すると、文字と同じ大きさのアイコンになります
ボタンやタグの中では部品の大きさのままで、fs-* を追加したときだけ変わります

確認しました 

<p>確認しました <svg data-suisou-text viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><path d="M5 12l5 5 9-10"/></svg></p>
<div data-suisou-layout="row wrap">
  <button><svg data-suisou="accent" data-suisou-text viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><path d="M5 12l5 5 9-10"/></svg>保存</button>
  <button><svg data-suisou-text="fs-16" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><path d="M5 12l5 5 9-10"/></svg>保存</button>
</div>

Reference

Values

ValueFunction
fs-12 fs-14 fs-16 fs-20 fs-24 fs-28 fs-32文字の大きさと行の高さを変える。数字はルートの文字が 16px のときの px
s: m: l:値の前に付けると、768 / 1024 / 1280px 以上でだけ効く。fs-* に付けられる
fw-400 fw-500 fw-700文字の太さを変える
start center end行の中で文字を寄せる位置を変える
pre-line文の中の改行をそのまま改行として出す（white-space: pre-line）。連続する空白は 1 つにまとめ、長い行は折り返す
breakURL のような切れ目の無い長い文字列を、はみ出す前にどこでも折り返す（overflow-wrap: anywhere）
clamp-1文字を1行に収め、はみ出した分を … にする。flex の子でも縮む
clamp-2文字を2行に収め、はみ出した分を … にする。flex の子でも縮む
link下線を付け、マウスを乗せるとアクセント色にする。画像だけのリンクには下線を付けない
typeset長文を組む。Typeset のページへ
toc入れ子の <ul> を目次にする。Toc のページへ
<svg> に付けたとき文字と同じ大きさの行内アイコンにする。ボタン・タグの中では部品の大きさのままで、fs-* があるときだけ文字の大きさになる
