Toc

Tocの適用

<ul> の data-suisou-text に toc を追加すると、目次になります

<ul data-suisou-text="toc">
  • 準備するもの
  • 立ち上げの手順
    • 1日目
    • 2日目〜1週間
  • 入れた生体
<ul data-suisou-text="toc">
  <li><a href="#toc">準備するもの</a></li>
  <li><a href="#toc">立ち上げの手順</a>
    <ul>
      <li><a href="#toc">1日目</a></li>
      <li><a href="#toc">2日目〜1週間</a></li>
    </ul>
  </li>
  <li><a href="#toc">入れた生体</a></li>
</ul>

階層

<ul> を入れ子にすると、3段階まで表示されます

  • 立ち上げの手順
    • 1日目
    • 2日目〜1週間
      • 水換え
      • 苔が出たら
  • 入れた生体
<ul data-suisou-text="toc">
  <li><a href="#toc">立ち上げの手順</a>
    <ul>
      <li><a href="#toc">1日目</a></li>
      <li><a href="#toc">2日目〜1週間</a>
        <ul>
          <li><a href="#toc">水換え</a></li>
          <li><a href="#toc">苔が出たら</a></li>
        </ul>
      </li>
    </ul>
  </li>
  <li><a href="#toc">入れた生体</a></li>
</ul>

現在のコンテンツ

リンクに aria-current を付けると、色が変わります

  • 準備するもの
  • 立ち上げの手順
    • 1日目
    • 2日目〜1週間
<ul data-suisou-text="toc">
  <li><a href="#toc">準備するもの</a></li>
  <li><a href="#toc">立ち上げの手順</a>
    <ul>
      <li><a href="#toc">1日目</a></li>
      <li><a href="#toc" aria-current="true">2日目〜1週間</a></li>
    </ul>
  </li>
</ul>

リンクでない項目

<a> の代わりに <span> で書くと、押せない見出しになります

  • 立ち上げ
    • 準備するもの
    • 手順
  • 入れた生体
<ul data-suisou-text="toc">
  <li><span>立ち上げ</span>
    <ul>
      <li><a href="#toc">準備するもの</a></li>
      <li><a href="#toc">手順</a></li>
    </ul>
  </li>
  <li><a href="#toc">入れた生体</a></li>
</ul>

Reference

Values

ValueFunction
toc入れ子の <ul> を目次にする。<ul> 自身にも、包む要素（<nav> など）にも付けられ、何段目かは <li> の入れ子の深さで決まる。1段目は 14px・塗りの丸、2段目は 14px・中抜きの丸、3段目は 12px・印なし。行の高さは 1・2段目 32px、3段目 28px。1段目の丸を縦線でつなぐ。文字は sub の色で、マウスを乗せると濃くなる
aria-current"false" 以外の値を付けたリンクは、文字と丸がアクセント色になる。ページの目次なら "page"、ページ内の目次なら "true" や "location"
<span>押せない見出しとして、リンクと同じ位置・色で置く
