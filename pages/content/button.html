Button

塗らない。CTA すらアウトライン。hover で面の明度は動かさず hover-surface を敷く。 基本形が「罫なし」なのは実測から —— wixdex の <button> 84個のうち 26個がアイコンのみで、単独では最大の塊だった。しかも hover 後の文字色が gray-300 と white に割れ、背景の有無も揃っていなかった。

使い方

値は空白区切り。~= で拾うので、いくつ並べても属性は1つのまま。 置き方は class（ユーティリティ）、状態は disabled や aria-* を借りる。

<button data-suisou-button="danger icon" aria-label="削除">

★danger の hover と active は色を動かしていない。仕様書に 「意味色は状態を持たない。destructive なボタンは v1.2 のスコープ外」とあり、 error の押下色が solve.py に無いため。下地だけで反応させている。

状態

★状態は標準の属性を借りる。 無効は disabled か aria-disabled="true"、 押しっぱなしは aria-pressed="true"。
Row は aria-selected / aria-current、 Field は disabled / aria-invalid を借りていて、 Button だけ data-suisou-button="on" と自前で持っていた。 寄せたので読み上げにも効くようになった。

形

icon … 正方形。padding 0 / aspect-ratio 1 / min-width 32px
block … 幅いっぱい

★当たり判定は 32px。タッチ目標の推奨は 44px なので、モバイルを踏むなら要検討。

アイコン

寸法は部品が持つ（--suisou-icon = 20px）ので、使う側は書かない。 wixdex では w-5 h-5 を各所で手書きしていた。 SVG が stroke="currentColor" なら色も自動で追随するので、 text-sub → text-main の変化がそのまま効く。 アイコンだけのボタンには aria-label が要る。

連結

data-suisou-button-group
wide —— 全幅の CTA。block（メニューの行・左寄せ）と違い中央寄せ
入力欄も飲み込める —— 検索バーが部品の組み合わせだけで組める

文字数が違っても幅は揃う（flex-basis 0 で割るため）
押せない文字も置ける —— data-suisou-affix（URL の接頭辞・単位など）
/@

親が罫と角丸を持ち、overflow で子を切る。子は角丸を持たないので 何個並んでも破綻しない。wixdex の検索欄がこの作りだった。
部品が2つ以上繋がったら、界面（枠・輪・角丸）は入れ物の仕事。 中の field は素肌になり、焦点の輪は入力中にグループ全体へ出る。
