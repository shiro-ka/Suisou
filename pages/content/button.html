Button

Buttonの適用

<button>タグの要素、 data-suisou-button を追加した要素はボタンになります

<button>
<a data-suisou-button>
a 
<div data-suisou-layout="row wrap">
  <button>button</button>
  <a data-suisou-button>a</a>
</div>

色

accent / error を追加すると、色が変わります

<div data-suisou-layout="row wrap">
  <button>ボタン</button>
  <button data-suisou="accent" data-suisou-button>accent</button>
  <button data-suisou="error" data-suisou-button>error</button>
</div>

outline

outline を追加すると、枠線が付きます

<div data-suisou-layout="row wrap">
  <button data-suisou-button="outline">outline</button>
  <button data-suisou="accent" data-suisou-button="outline">outline accent</button>
  <button data-suisou="error" data-suisou-button="outline">outline error</button>
</div>

icon

icon を追加すると、アイコンだけの正方形ボタンになります

<button data-suisou-button="icon"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><path d="M12 5v14M5 12h14"/></svg></button>

block

block を追加すると、横幅いっぱいに広がり、中身が左寄せになります

<button data-suisou-button="block">block</button>

状態

aria-pressed="true" / aria-current を付けると、選択中の背景になります
disabled を付けると、押せない見た目になります

<div data-suisou-layout="row wrap">
  <button aria-pressed="true">オン</button>
  <button aria-pressed="false">オフ</button>
  <button disabled>disabled</button>
</div>

data-suisou の色の語accent error success warning で、文字をその色にし、押している間はその色の背景にする。sub では、マウスを乗せても文字が濃くならない
outline罫線を付ける。色の語と一緒に書くと、罫線もその色になる
iconアイコンだけの、32px の正方形にする
block横幅いっぱいにし、中身を左に寄せる。横の余白は 16px
