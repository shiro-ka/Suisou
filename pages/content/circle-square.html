Circle / Square

Circle / Squareの適用

要素に data-suisou-item="circle" を追加すると、丸い枠になります
data-suisou-item="square" を追加すると、角丸の四角い枠になります

<div data-suisou-item="circle">
<div data-suisou-item="square">
し
<div data-suisou-layout="row wrap">
  <div data-suisou-item="circle">し</div>
  <div data-suisou-item="square"><svg data-suisou-text="fs-20" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><circle cx="12" cy="12" r="9"/></svg></div>
</div>

中身

文字・画像・アイコンを入れることができます

し
し

  <div data-suisou-item="circle">し</div>
  <div data-suisou-item="circle"><svg data-suisou-text="fs-20" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><circle cx="12" cy="12" r="9"/></svg></div>
  <div data-suisou-item="square">し</div>

</div>

Reference

Values

ValueFunction
circle丸い枠にする。大きさは --suisou-circle（既定 2rem）
square角丸の四角い枠にする。大きさは --suisou-square（既定 2rem）
共通背景を item の色にし、細い罫線を付ける。中身を縦横の真ん中に置き、はみ出した部分は切り取る。文字は 12px の薄い色。<img> に付けると、歪まずに切り抜かれる。伸び縮みしない
smallcircle square と一緒に使う。1.5rem にする
largecircle square と一緒に使う。3rem にし、文字を 16px にする

CSS

@property --suisou-circle { syntax: "*"; inherits: false; }
@property --suisou-square { syntax: "*"; inherits: false; }

[data-suisou-item~="circle"], [data-suisou-item~="square"] {
  flex: none;
  background: var(--suisou-item);
  --suisou-line-weak: var(--suisou-line-weak-item);
  --suisou-line-strong: var(--suisou-line-strong-item);
  border: 1px var(--suisou-bd-style, solid) var(--suisou-line-weak);
  color: var(--suisou-text-sub);
  font-size: var(--suisou-size-12);
  line-height: var(--suisou-lh-12);
  display: grid;
  place-items: center;
  padding: 0;
  overflow: hidden;
  object-fit: cover;
}
[data-suisou-item~="circle"] {
  width: var(--suisou-circle, 2rem);
  height: var(--suisou-circle, 2rem);
  border-radius: var(--suisou-radius-pill);
}
[data-suisou-item~="square"] {
  width: var(--suisou-square, 2rem);
  height: var(--suisou-square, 2rem);
  border-radius: var(--suisou-radius);
}
[data-suisou-item~="circle"]:where([data-suisou-item~="small"]) { --suisou-circle: 1.5rem; }
[data-suisou-item~="circle"]:where([data-suisou-item~="large"]) { --suisou-circle: 3rem; font-size: var(--suisou-size-16); }
[data-suisou-item~="square"]:where([data-suisou-item~="small"]) { --suisou-square: 1.5rem; }
[data-suisou-item~="square"]:where([data-suisou-item~="large"]) { --suisou-square: 3rem; font-size: var(--suisou-size-16); }
