Media

先頭に固定幅のもの、右に可変の本文。2010年に OOCSS で提唱された形で、 Bootstrap も Bulma も media と呼んでいた。 チャットの発言・コメント・通知・検索結果と繰り返し出てくる。 作例では14箇所に使っている。

3つの区画

中身は位置ではなく名前で当てるので、並び順を変えても壊れない。 -icon と -tail は縮まず、 -content が余りを取る。

区画ふるまい入れるもの
data-suisou-media-icon縮まない Avatar、Icon、チェックボックス
data-suisou-media-content 余りを取る（min-width: 0 つき） <header> と <p>
data-suisou-media-tail縮まない 件数、時刻、操作

中の header と p は整えてある

-content の中の <header> と <p> にだけ、要素で直接当てている。 :where() で詳細度を 0 にしてあり、しかも -content の内側にしか効かないので、 適用先の <header> には漏れない。

要素扱い
header横並び・折り返す・ベースライン揃え
header の1つ目14px / 600。名前や題
header の2つ目以降12px / text-sub。時刻や補足
p14px、margin: 0

これは base.css の「要素セレクタは使わない」を小さく破っている場所。 破っていい範囲を属性の内側に限るという形で、 長文用の prose も同じ手を使うことになる。

面を持たない

触るのは並び方だけなので、面の部品と同じ要素に同居できる。 panel を作って中に media を入れる、という段を踏まなくていい。

<div data-suisou-surface="panel" data-suisou-row data-suisou-media>
