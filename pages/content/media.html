Media

Mediaの適用

要素に data-suisou-item="media" を追加します
子要素は、media-figure / media-content / media-tail があります

<div data-suisou-item="media">
し
しろか.04:06

ご機姸よう

<div data-suisou-item="media">
  <div data-suisou-item="media-figure circle">し</div>
  <div data-suisou-item="media-content">
    <header><span>しろか.</span><span>04:06</span></header>
    <p>ご機姸よう</p>
  </div>
  <button data-suisou-item="media-tail">⋮</button>
</div>

media-figure

アイコン・画像等の部分です
左端の列になり、幅は中身のままで、伸び縮みしません
大きさと形は中身で決まります。circle や square と一緒に書くと、その大きさと形になります
中身は、media-content の1行目の高さの真ん中に揃います

<div data-suisou-item="media-figure circle">
<div data-suisou-item="media-figure square">

media-content

メインコンテンツの部分です
残りの幅をすべて使います

header

1つ目は太字、2つ目以降は小さく薄い文字になります

media-tail

右端の列になります
幅は中身のままで、伸び縮みしません

Reference

Values

ValueFunction
media子要素を横に並べる。間隔は 8px、上端で揃える。背景・罫線・余白は付かない
media-figure幅は中身のままで、伸び縮みしない。高さの下限は 14px の文字1行分で、中身を縦の真ん中に置く。画像のときは、大きさが決まると歪まずに切り抜かれる。circle square と一緒に書ける
media-content残りの幅をすべて使い、子要素を 4px 間隔で縦に並べる。中の <header> は子要素を横に並べ、1つ目を 14px の太字、2つ目以降を 12px の薄い文字にする。中の <p> は 14px
media-tail幅は中身のままで、伸び縮みしない
