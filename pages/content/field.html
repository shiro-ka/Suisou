Field

Fieldの適用

要素に data-suisou-item="field" を追加すると、中の入力欄・ボタン・文字が1つの欄になります

<div data-suisou-item="field">
@ 
<div data-suisou-item="field">
  <span>@</span>
  <input placeholder="ハンドルを入力">
  <button>確認</button>
</div>

中に置けるもの

直下の子要素によって、見た目が変わります

input / textarea / select

罫線と背景が消え、残りの幅をすべて使います

<div data-suisou-item="field">
  <input>
</div>
<div data-suisou-item="field">
  <select><option>選択肢</option></select>
</div>
<div data-suisou-item="field">
  <textarea></textarea>
</div>

button

罫線と角丸が消え、欄の端にくっつきます

<div data-suisou-item="field">
  <input>
  <button>確認</button>
</div>

span

入力欄の前に付く、薄い文字になります

@ 
<div data-suisou-item="field">
  <span>@</span>
  <input>
</div>

状態

aria-invalid="true" で赤い枠に、disabled で薄い枠になります

@
@ 
<div data-suisou-item="field">
  <span>@</span>
  <input aria-invalid="true">
</div>
<div data-suisou-item="field">
  <span>@</span>
  <input disabled>
</div>

Reference

Values

ValueFunction
field子要素を横に並べて1つの欄にする。背景は置いた場所より一段上の色、濃い罫線・角丸。直下の <input> <textarea> <select> は罫線と背景を消して残りの幅を使い、フォーカスの枠は欄全体に付く。直下の <button> は罫線と角丸を消す。直下の <span> は薄い文字にして、左に 8px 空ける。中の入力欄が aria-invalid="true" なら罫線を赤く、無効なら罫線を薄くして背景を消す
