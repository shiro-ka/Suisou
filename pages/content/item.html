Item

Itemの適用

要素に data-suisou-item を追加すると、アイテムになります

<div data-suisou-item>
アイテムはパネルの上に置きます
<div data-suisou-item>アイテムはパネルの上に置きます</div>

種類

値に1つアイテムの種類を指定することができます
詳細は各アイテムのページまで

media

し
しろか.04:06

ご機姸よう

circle / square

し

tag

タグ

notice

確認メールを送信しました

field

Reference

Values

ValueFunction
media画像・本文・末尾を横に並べた1件分にする
circle丸い枠にする
square角丸の四角い枠にする
tag小さい丸みのあるラベルにする
notice知らせの箱にする
field入力欄とボタンなどを1つの枠にまとめる

CSS

@property --suisou-circle { syntax: "*"; inherits: false; }
@property --suisou-square { syntax: "*"; inherits: false; }

[data-suisou-item] { text-decoration: none; }

[data-suisou-item=""] {
  border: 1px var(--suisou-bd-style, solid) var(--suisou-line-weak);
  border-radius: var(--suisou-radius);
  padding: var(--suisou-space-2);
  background: var(--suisou-item);
  --suisou-line-weak: var(--suisou-line-weak-item);
  --suisou-line-strong: var(--suisou-line-strong-item);
  --suisou-next: var(--suisou-item);
  --suisou-line-weak-next: var(--suisou-line-weak-item);
  --suisou-line-strong-next: var(--suisou-line-strong-item);
}
