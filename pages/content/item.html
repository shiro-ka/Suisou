要素に data-suisou-item を追加すると、アイテムになります

<div data-suisou-item>
アイテムはパネルの上に置きます

Reference

Values

ValueFunction
circle丸い枠にする
square角丸の四角い枠にする
tag小さい丸みのあるラベルにする
notice知らせの箱にする
field入力欄とボタンなどを1つの枠にまとめる
media画像・本文・末尾を横に並べた1件分にする

@property --suisou-size-circle { syntax: "*"; inherits: false; }
@property --suisou-size-square { syntax: "*"; inherits: false; }

[data-suisou-item] { text-decoration: none; }

  border-radius: var(--suisou-radius);

  background: var(--suisou-color-item);
}
