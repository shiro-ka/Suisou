Tag

Tagの適用

要素に data-suisou-item="tag" を追加すると、タグになります

<span data-suisou-item="tag">

タグ

<span data-suisou-item="tag">タグ</span>

色

accent / error / warning / success を追加すると、色が変わります

タグ accent error warning success 
<div data-suisou-layout="row wrap">
  <span data-suisou-item="tag">タグ</span>
  <span data-suisou-item="tag accent">accent</span>
  <span data-suisou-item="tag error">error</span>
  <span data-suisou-item="tag warning">warning</span>
  <span data-suisou-item="tag success">success</span>
</div>

アイコン

中に svg を置くと、大きさが調整されます

確認済み

<span data-suisou-item="tag success"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><path d="M4 12l5 5L20 6"/></svg>確認済み</span>

リンク・ボタン

<a>, <button> をタグにすることもできます

<button data-suisou-item="tag">タグ</button>

Reference

Values

ValueFunction
tag行の中に置く小さいラベルにする。文字は 12px の薄い色、細い罫線、角は丸く、背景は無い。横の余白は 8px。直下の <svg> は 16px になり、文字との間は 4px。<a> <button> では、マウスを乗せると背景が付く
accent error warning successtag と一緒に使う。罫線と文字をその色にする
