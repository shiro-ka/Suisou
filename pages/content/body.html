Body

Suisouの適用

要素に data-suisou-body を追加すると、その要素と中の要素にSuisouが適用されます

<body data-suisou-body>

ページの一部に対してのみSuisouを使用する場合、<div> 等に追加することも可能です
全体に対してSuisouを使用する場合は、<body> に対して追加することが推奨です

shell

<body> の data-suisou-body に shell を追加すると、ページの枠組みが作成されます
shell 直下の要素 <header>, <main>, <footer>, <nav> が、自動的に配置されます

<body data-suisou-body="shell">
  <header>header</header>
  <main>main</main>
  <footer>footer</footer>
  <nav>nav</nav>
</body>

(ミニプレビュー)

ページは画面の高さに固定され、本体はスクロールしません

doc

ページ本体がスクロールするようになり、<nav> は画面に固定されます

<body data-suisou-body="shell doc">

right

<nav> が右側に配置されます

<body data-suisou-body="shell right">

dock

<nav> に popover を追加すると、ドロワーになり、端から滑って出てきます
s:dock / m:dock / l:dock を追加すると、768 / 1024 / 1280px 以上では <nav popover> が閉じた状態でも表示されます

<body data-suisou-body="shell m:dock">
  <nav popover>

なしその要素と中の要素に、フォント・背景色・文字色、余白のリセット、<button> <input> <a> などの既定の見た目、細いスクロールバーを適用する
shell<body> のみ。直下の <header> <main> <footer> <nav> を配置し、ページを画面の高さに固定する。<nav> は高さいっぱいで、中身が多いとスクロールする。<main> には四方 16px の余白が付く。ほかの要素の位置は決まっていない
docshell と一緒に使う。ページ本体がスクロールし、<nav> は画面に固定される
rightshell と一緒に使う。<nav> を右側に配置する。<nav popover> は右から滑って出る
s:dock m:dock l:dockshell と一緒に使う。直下の <nav popover> を、768 / 1024 / 1280px 以上では出しっぱなしのサイドバーにする（背景・罫線なし、幅は中身に合わせて 14〜20rem）。それより狭いと、閉じていて、開くと端から滑って出る
